# Akan Name Generator

## Project Description
The Akan Name Generator is a web application that allows users to discover their Akan name based on their dates of birth and their gender. This tool follows the Akan tradition where names are assigned according to the day of the week a person is born.

## Setup Instructions
1. Clone the repository to your local machine:
2. Open `index.html` in your web browser to use the application.

## BDD (Behavior-Driven Development)
- When the user enters his/her date of birth and gender,  the corresponding Akan name is displayed.
- When the user enters an invalid date or does not select a gender, an alert message informs them of the error.
